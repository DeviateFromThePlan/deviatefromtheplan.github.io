Restore my setup

Everything I need to get WME back to how I like it on a new computer. Work through the steps in order.

1 Install the extensions

Tampermonkey Runs the userscripts.
Chrome Edge Firefox
WME Toolbox Browser extension, updates itself. Its options and shortcuts come back with my settings in step 4.
Chrome Other browsers
Chrome only: after installing Tampermonkey, open chrome://extensions , click Details on Tampermonkey and turn on Allow User Scripts. Scripts won’t run without it.

2 Install the userscripts

Fastest: install everything at once
  1. Open the Tampermonkey dashboard → Utilities.
  2. Under Import from URL, paste this link and click Install, then Import:
  3. Back on Installed Userscripts, tick the box at the top to select all, choose Trigger update and click Start, so every script jumps to its latest version.
Then install anything new from the list below that isn’t in the bundle yet.

Or one at a time: each link is the script’s own update address, so you always get the latest version. Tampermonkey opens an install page for each one: click Install, then come back here.

    WME Send to Discord (Reloaded) replaces the older WME Send to Discord: uninstall the old one first if it’s there.

    3 Open WME and sign in

    Open WME Waze forum

    Scripts that ask to connect to other sites (Google Sheets, Discord, GitHub): choose Always allow for that domain.

    4 Restore my WME settings

    In WME, open the Scripts tab → ESM (Easy Storage Manager). Connect Google Drive and import my latest backup, or import a backup file. Pick the settings to bring back and WME reloads with them.

    Once Google Drive is connected, turn on ESM’s auto-save so there’s always a recent backup. ESM forum thread

    5 Reconnect site stats

    In WME, click the Tampermonkey icon → WME Site Stats Sync → Set GitHub token. Use a fine-grained token with only Gists: Read and write (create one). The script finds and keeps using the existing stats gist.
